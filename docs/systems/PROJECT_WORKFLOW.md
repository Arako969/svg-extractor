# Produktionsworkflow

## Empfohlener Ablauf

1. Outline öffnen.
2. Regionen analysieren.
3. Optional Farbvorlage laden.
4. Palette analysieren.
5. Problemregionen korrigieren.
6. Logische Game Areas bilden.
7. Farb-IDs prüfen.
8. Label-Positionen setzen.
9. Projekt speichern.
10. Game SVG, Game JSON, Outline PNG und bei Bedarf Preview exportieren.

## Korrekturwerkzeuge

- adaptive Mikroregionen
- farbbasierte Unterregionen
- Color Recovery
- fehlende Fläche manuell hinzufügen

## Typische bisher dokumentierte Startwerte

- Schwarz/Weiß-Schwelle: `190`
- Lücken schließen: `3`
- Pfad-Vereinfachung: `1.5`
- Mindestfläche: motivabhängig
- Palette: häufig `8` bis `24` Farben

Diese Werte sind Startpunkte und keine verbindlichen Konstanten.
