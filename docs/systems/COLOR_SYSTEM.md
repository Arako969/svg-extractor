# Farbsystem

## Farbvorlage

Eine kolorierte Referenz ist optional. Im Idealfall besitzt sie dieselbe Geometrie, denselben Ausschnitt und dieselbe Position wie die Outline. Abweichende Auflösungen können skaliert werden.

## Farbanalyse

Pixel innerhalb einer Region werden aus der Referenz ausgewertet. Sehr dunkle und sehr helle Pixel können optional ignoriert werden.

Für jede Region wird eine repräsentative Ziel-Farbe bestimmt.

## Palette

Ähnliche Farben werden zu einer reduzierten Palette zusammengefasst. Die gewünschte Anzahl ist einstellbar, beispielsweise 8, 12, 16 oder 24 Farben.

## Farb-ID

Jede Region beziehungsweise Game Area erhält eine Farb-ID als spätere Malen-nach-Zahlen-Nummer. Die ID verweist auf eine Palettenfarbe und deren Ziel-Farbwert.

## Grenzen

Starke Farbverläufe und Schattierungen werden bewusst auf repräsentative Farben reduziert. Dies entspricht dem aktuellen Malen-nach-Zahlen-Ziel.
